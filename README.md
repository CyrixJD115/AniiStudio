# AniiStudio
AniiStudio

The native macOS companion source is under [macos/AniimoAtlas](macos/AniimoAtlas/README.md). It reconstructs captured Homeland placements with native 3D models and supports local drafts; production game/server writeback remains unimplemented.

Review the [October 24 implementation findings](docs/homeland-progress-2026-10-24.md) and [offline world tooling](research/homeland-world/README.md) for verified scope, tests, missing assets and attribution. Player captures, game models/textures and credentials are excluded.
